# LAB1 — лабораторная работа № 1

Учебный проект по дисциплине **«Теория алгоритмов»**.  
Тема лабораторной работы — **введение в язык программирования Python**.

## Что реализовано

В каталоге `lab_01` находятся 11 заданий, посвящённых базовым конструкциям Python: вычислениям, строкам и срезам, спискам, словарям и множествам.

Помимо отдельных заданий в проекте есть:

- `run_lab.py` — запускает все задания последовательно
- `tests/test_tasks.py` — автоматизированные проверки на `pytest`
- `requirements.txt` — зависимости проекта
- `.gitignore` — исключения для Git

## Запуск

Для работы рекомендуется использовать виртуальное окружение Python.

```bash
python -m venv .venv
```

После активации окружения установить зависимости:

```bash
python -m pip install -r requirements.txt
```

### Отдельное задание

Например:

```bash
python lab_01/00_distance.py
```

### Все задания сразу

```bash
python run_lab.py
```

`run_lab.py` загружает файлы из `lab_01` по пути через `importlib.util.spec_from_file_location()` и вызывает функцию `run()` каждого модуля. Такой способ выбран потому, что имена файлов начинаются с цифр и их неудобно импортировать обычным `import`.

## Тестирование

Запуск всех тестов:

```bash
python -m pytest -v
```

В проекте реализовано 13 тестов. Они проверяют вычислительные функции заданий через `assert`, а не сравнивают текст, напечатанный в консоль.
